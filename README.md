# Console Expense Manager

Простой консольный менеджер расходов на Python для учета личных финансов.

## 📋 Функциональность

- ✅ **Добавление расходов** по категориям с указанием даты и суммы
- ✅ **Просмотр всех расходов** с различными вариантами сортировки:
  - По дате (новые сверху)
  - По сумме (от больших к меньшим)
  - По категории (алфавитный порядок)
  - Без сортировки
- ✅ **Статистика за конкретный день**
- ✅ **Общая статистика** по всем расходам
- ✅ **Статистика по категориям**:
  - Количество записей по категориям
  - Сумма расходов по категориям
  - Самая частая категория
  - Самая затратная категория
- ✅ **Автосохранение данных** в форматах CSV и JSON
- ✅ **Загрузка данных** из файла при запуске

## 🚀 Установка и запуск

### Требования
- Python 3.6 или выше
- Никаких дополнительных библиотек не требуется

# Перейдите в папку проекта
